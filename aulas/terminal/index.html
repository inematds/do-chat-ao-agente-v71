Aula 2

Degrau 1: do chat para o terminal (OSWork)

O terminal é só outra janela. Com seis comandos você anda pelas suas pastas; com um AGENTS.md o agente sabe quem você é e o que pode fazer; com o Git você desfaz qualquer erro.

12 minPróxima aula

Nesta aula, você vai aprender:

  • Andar pelas pastas pelo terminal
  • Escrever o manual do agente (AGENTS.md)
  • Desfazer qualquer mudança com o Git
  • Manter chaves fora do texto

Objetivo: montar a pasta de trabalho do agente com regras, rede de segurança e segredos fora do texto.

1

Como as peças se ligam

Você dá a tarefa, o agente trabalha dentro da pasta e você confere.

Não gostou? git restore volta o arquivo para a última versão salva
Clique em cada bloco do diagrama para ver o que ele faz.

Os mesmos arquivos servem para o Claude Code e para o Codex: os dois leem o AGENTS.md.

2

O ciclo de trabalho com o agente

Clique em cada etapa.

1. Pedir

Dentro da pasta, chame claude ou codex e peça uma coisa só, com o resultado que você espera.

Comece pedindo para ler o AGENTS.md: assim ele usa as suas regras.

PedidoLeia o AGENTS.md. Crie um index.html com uma página simples sobre mim, usando o que está lá.

2. Executar

O agente cria e edita arquivos na pasta. Ele pode pedir permissão antes de rodar comandos.

Seu papel aqui é ler o que ele propõe, não digitar por ele.

O que apareceO agente cria o index.html e explica o que fez.

3. Conferir

Abra o resultado (a página no navegador, o resumo, o arquivo) e compare com o que você pediu.

Peça pelo menos uma correção: é o hábito que separa usar de gerenciar.

CorreçãoTroque o título por "Consultoria de RH" e acrescente uma seção de contato.

4. Salvar ou desfazer

Gostou? git add . e git commit -m "..." guardam a versão.

Não gostou? git restore index.html volta ao que estava salvo, sem pânico.

Regra de ouroFaça um commit antes de pedir uma mudança grande.
3

Os arquivos e comandos da sequência

Copie e use. Troque o texto entre os sinais < > pelo seu.

Terminal · primeira pasta
mkdir projetos
cd projetos
mkdir meu-primeiro-agente
cd meu-primeiro-agente
dir      # Windows (no Mac e no Linux: ls)
AGENTS.md
# Quem sou
<seu nome, sua profissão, para quem você trabalha>

# Regras deste projeto
- Escreva em português, frases curtas.
- Não apague arquivos sem perguntar.
- Antes de terminar, diga o que mudou e como eu confiro.
- Nunca escreva chaves ou senhas em arquivo de texto; elas ficam no .env.

# O que tem aqui
- index.html: minha página
Terminal · Git e segredo fora do texto
git init
echo .env> .gitignore
git add .
git commit -m "primeira versão"

# desfazer uma mudança do agente:
git restore index.html

# o .env NÃO pode aparecer aqui:
git status
Exemplo do repositório
  1. Você chega à pasta só pelo terminal e sabe dizer em que pasta está.
  2. O AGENTS.md tem pelo menos três regras escritas por você.
  3. A página abre no navegador e você pediu ao menos uma correção.
  4. git status não mostra o .env.
  • Pular o Git: a primeira mudança ruim do agente vira retrabalho manual.
  • Chave no AGENTS.md: tudo o que está em texto pode ir parar no GitHub. Chave só no .env.
  • Pedido vago: "melhore a página" gera mudança que você não sabe conferir. Peça um resultado que dá para ver.
4

Prática: os 6 exercícios da sequência 1

Faça na ordem. Só passe para o próximo quando o "pronto quando" for verdade.

E1 · Primeira pasta pelo terminal

10 min

Crie projetos/meu-primeiro-agente, entre nela e liste o conteúdo. Abra a mesma pasta no Explorador (ou Finder) e compare.

Pronto quando: você chega à pasta só pelo terminal, sem o mouse, e sabe dizer em que pasta está.

E2 · O manual do funcionário

15 min

Crie o AGENTS.md com quem você é, as regras do projeto e o que tem na pasta.

Pronto quando: o arquivo existe e tem pelo menos três regras suas, escritas por você.

E3 · A primeira tarefa

15 min

Chame o agente e peça o index.html a partir do AGENTS.md. Abra no navegador e peça uma mudança.

Pronto quando: a página abre e você pediu pelo menos uma correção ao agente.

E4 · A rede de segurança

20 min

git init, add e commit. Peça uma mudança grande e, se não gostar, volte com git restore.

Pronto quando: você desfez uma mudança do agente com um comando, sem pânico.

E5 · Segredo não entra no texto

10 min

Crie um .env com uma chave falsa e um .gitignore com a linha .env. Acrescente a regra ao AGENTS.md.

Pronto quando: git status não mostra o .env.

E6 · O agente lê os seus arquivos

20 min

Coloque três textos seus na pasta e peça um resumo.md com 5 decisões e 5 pendências, citando a origem de cada uma.

Pronto quando: você achou no original pelo menos duas das frases citadas.

Exercícios completos, com o desafio extra (repetir com o outro agente): jornada-agentes/exercicios/01-oswork.md.
